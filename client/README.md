# 🌊 Dayflow HRMS - Frontend Client

This is the frontend user interface for **Dayflow HRMS**, built with **React 18**, **Vite**, **TailwindCSS v4**, and **Lucide Icons**.

## 🎨 Overview & Features
- **Odoo-Inspired Aesthetic**: Modern claymorphic design system with vibrant brand colors (`#714B67`, `#017E84`) and custom typography (`Outfit`).
- **Responsive Layout**: Designed for seamless usage across desktop and mobile screens.
- **Authentication**: JWT integration with localStorage persistence and interactive Login interface.

## 🚀 Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

For full documentation and upcoming implementation plans, please refer to the [Root README](../README.md).
